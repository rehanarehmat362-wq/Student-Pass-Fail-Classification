# Student Pass/Fail Classification Using Logistic Regression

## Project Overview

This project uses Machine Learning to predict whether a student may pass or fail based on three factors:

- Study Hours
- Attendance
- Previous Exam Score

A Logistic Regression classification model is trained using a synthetic student dataset.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook

## Machine Learning Workflow

1. Dataset creation
2. Data inspection and cleaning
3. Exploratory Data Analysis (EDA)
4. Feature and target selection
5. Train-test split
6. Logistic Regression model training
7. Predictions
8. Model evaluation
9. Confusion matrix visualization
10. Prediction probability visualization
11. Saving the trained model

## Model Evaluation

- Test accuracy: 100%
- Test samples: 4

**Important:** The dataset is synthetic and contains only 20 student records. The 100% test accuracy is a demonstration result, not evidence of real-world performance.
